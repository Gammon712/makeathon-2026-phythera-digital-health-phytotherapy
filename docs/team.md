# Team and division of work

PhyThera was built by an interdisciplinary two-person team.

## Pharmacist / phytotherapy domain expert
Primary contributions:
- phytotherapy and medicinal-plant domain knowledge,
- EMA/HMPC and regulatory interpretation,
- clinical relevance and safety framing,
- source interpretation,
- evidence terminology and user perspective.

## Biochemist / data & programming
Primary contributions:
- scientific evidence architecture,
- Supabase database design,
- n8n workflow implementation,
- API and PubMed integration,
- deterministic scoring logic,
- Streamlit frontend and data integration.

## Shared work
Both team members contributed to:
- project concept,
- source selection,
- validation rules,
- interpretation guardrails,
- evidence-model design,
- testing,
- user experience,
- scientific communication.

This division intentionally combines domain expertise with computational implementation, reflecting EthnoHack's interdisciplinary objective.
